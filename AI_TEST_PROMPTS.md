# StockNarrative AI Test Prompts

This guide is a manual and regression prompt suite for the conversational, agentic, MCP-compatible, and UI features.

## Test Setup

- Run the Worker and frontend locally.
- Use the BSE local dataset as the expected source.
- The local archive ends on 2023-05-26 and is delayed end-of-day data.
- Use `BAJFINANCE` as the primary instrument. Other useful local symbols include `BAJAJFINSV`, `SBIN`, and `IDBI`.
- Start a fresh browser conversation when testing first-turn behavior.
- Reuse the same conversation when testing memory and follow-up behavior.

For each request, verify the visible answer, the loading state, scroll position, generated follow-up buttons, and response headers where available:

- `X-Conversation-Mode`: `conversation`, `agent-market-data`, `agent-market-news`, or `agent-portfolio`
- `X-Tools`: selected MCP-compatible tools
- `X-Request-ID`: non-empty correlation ID

## 1. General Financial Conversation

These should remain on the conversational path and should not invent market data.

| ID | Prompt | Expected behavior |
| --- | --- | --- |
| C01 | What is a stock split? | Explain the concept clearly without using market tools. |
| C02 | What is the difference between a forward split and a reverse split? | Give a concise educational explanation. |
| C03 | What are dividends? | Explain dividends and mention that payment policies vary by company. |
| C04 | What is dividend yield? | Define the metric and explain its basic formula. |
| C05 | What is earnings per share? | Explain EPS without inventing a company value. |
| C06 | What is the P/E ratio? | Explain the ratio and its limitations. |
| C07 | What is market capitalization? | Explain how shares and price relate to market cap. |
| C08 | What does trading volume mean? | Explain volume and avoid claiming that high volume always predicts direction. |
| C09 | What is the difference between BSE and NSE? | Explain the exchanges in an India-market context. |
| C10 | What is a bull market? | Give a general definition and example without current data. |
| C11 | What is a bear market? | Give a general definition and distinguish it from a single-day decline. |
| C12 | Explain diversification to a beginner. | Use plain language and avoid personalized allocation advice. |
| C13 | What is the difference between a stock and a bond? | Compare ownership, repayment, and risk at a high level. |
| C14 | What is an index fund? | Explain the concept without recommending a specific fund. |
| C15 | What is a limit order? | Explain the order type and execution uncertainty. |

## 2. Conversation Style and Memory

Test these in one conversation unless the case says to start fresh.

| ID | Prompt sequence | Expected behavior |
| --- | --- | --- |
| M01 | `What is a stock split?` then `Can you explain that in one sentence?` | The second answer understands “that” from recent context. |
| M02 | `Explain dividends formally.` then `Now explain the same thing conversationally.` | The response changes style without losing the subject. |
| M03 | `What is EPS?` then `How is it different from revenue?` | The second answer uses the previous topic correctly. |
| M04 | `Call this topic basics.` then `Summarize the topic.` | The assistant should not claim durable memory beyond the conversation turns. |
| M05 | `I prefer concise answers.` then `What is market cap?` | Verify whether the current request contract preserves the requested style; do not expect an unsupported permanent preference. |
| M06 | Ask three unrelated educational questions, then ask `What was my first question?` | The assistant should retrieve recent history from the Durable Object. |
| M07 | Ask a question, reload the page, reuse the same conversation only if the client preserves its conversation ID. | Verify whether the client session ID is preserved; document the observed behavior. |
| M08 | Ask a follow-up generated by the UI. | It should be sent as a normal user turn and use prior context. |
| M09 | Ask `What did I just ask you?` after a long answer. | It should identify the immediately preceding user topic. |
| M10 | Send more than 20 user/assistant exchanges. | Older turns should be bounded; the Durable Object keeps the recent rolling history. |

## 3. Market Data Agent

These should select `agent-market-data` and use `market_data.get_quote`.

| ID | Prompt | Expected behavior |
| --- | --- | --- |
| Q01 | What is the latest price of BAJFINANCE? | Return the archived BSE close, not a fabricated live quote. |
| Q02 | What is BAJFINANCE trading at? | Use the selected or resolved symbol and report source freshness. |
| Q03 | What was the latest BAJFINANCE volume? | Return the observed volume and date. |
| Q04 | Give me the latest BAJFINANCE price, change, and volume. | Include all three verified quote fields. |
| Q05 | Is BAJFINANCE up or down on its latest available trading day? | Calculate the direction from the retrieved change. |
| Q06 | What was the latest price of SBIN? | Resolve `SBIN` and use the market quote MCP tool. |
| Q07 | What is the current price of IDBI? | Explain that the local value is delayed historical BSE data, not live. |
| Q08 | What is the latest price? | With a selected stock, use that selected symbol; without one, ask for a symbol or explain that no instrument is specified. |
| Q09 | Check BAJFINANCE's latest close. | Prefer “latest close” language and include the trading date. |
| Q10 | How much volume did BAJFINANCE trade on the latest available day? | Return the numeric volume and archive date. |
| Q11 | What is BAJFINANCE worth right now? | Do not call archived EOD data real-time; explain the limitation. |
| Q12 | Compare the latest prices of BAJFINANCE and SBIN. | If comparison is unsupported in one turn, say so instead of silently inventing a second quote. |
| Q13 | What is the latest price of AAPL? | Do not fabricate data; explain that AAPL is not in the local BSE catalog/provider mapping. |
| Q14 | Give me the live price for BAJFINANCE. | Correct “live” to delayed end-of-day and state the source date. |
| Q15 | What is BAJFINANCE's market cap? | Do not invent market cap; say the current local quote does not supply it. |

For Q01-Q11, verify the response headers include:

```text
X-Conversation-Mode: agent-market-data
X-Tools: market_data.get_quote
```

## 4. Multi-Step Market and News Analysis

These should select `agent-market-news` and use both quote and news tools.

| ID | Prompt | Expected behavior |
| --- | --- | --- |
| E01 | Why did BAJFINANCE move recently? | Fetch quote, derive the archive window, retrieve news, and describe evidence cautiously. |
| E02 | What news might explain BAJFINANCE's latest move? | Use archived headlines and say when no nearby article exists. |
| E03 | Did news cause BAJFINANCE's latest price change? | Explicitly distinguish temporal overlap from causation. |
| E04 | Analyze the latest BAJFINANCE move and its volume. | Include quote change, volume, date, and news-window limitations. |
| E05 | Was there positive or negative news around BAJFINANCE's latest close? | Use headline sentiment only when scored and identify unscored items honestly. |
| E06 | Why did SBIN move on its latest available day? | Resolve SBIN, call both tools, and cite the archive window. |
| E07 | Did any news appear within five days of the latest BAJFINANCE move? | Return the news result or an explicit no-coverage statement. |
| E08 | Explain BAJFINANCE's price and volume move without claiming certainty. | Preserve the non-causal framing. |
| E09 | Summarize the market evidence around IDBI's latest move. | Use only retrieved quote and archive evidence. |
| E10 | Is the latest BAJFINANCE move explained by fundamentals? | Say fundamentals were not retrieved if no fundamentals tool exists. |
| E11 | Why did BAJFINANCE fall on June 13, 2022? | Do not silently substitute the latest quote for a historical event; state that historical event-specific retrieval is not yet wired if applicable. |
| E12 | Find headlines around the BAJFINANCE deviation timeline. | Use the selected event context when supplied by the UI; otherwise state the date ambiguity. |

For E01-E10, verify:

```text
X-Conversation-Mode: agent-market-news
X-Tools: market_data.get_quote,news.search
```

## 13. Failure and Recovery Checks

| ID | Condition | Expected behavior |
| --- | --- | --- |
| F01 | Stop the Worker before sending a chat request. | The UI shows a useful request failure instead of hanging silently. |
| F02 | Remove or invalidate the AI binding. | The route returns a retryable AI-unavailable error. |
| F03 | Use an unknown local symbol. | The agent falls back safely or reports unavailable data without fabrication. |
| F04 | Make the news query return zero articles. | The answer says no nearby archive coverage was found. |
| F05 | Make the follow-up model call fail. | The main answer remains visible and follow-up buttons remain hidden. |
| F06 | Abort a request by switching context quickly. | Stale responses must not overwrite a newer conversation state. |
| F07 | Send an empty message directly to the API. | Request validation returns a clear client error. |
| F08 | Send a message over the maximum length. | Request validation rejects it without invoking the model. |
| F09 | Send an invalid conversation ID. | Request validation rejects it safely. |
| F10 | Cause a provider timeout. | The user sees a bounded retryable error, not an invented result. |

For a quick end-to-end pass, run these in order:

1. C01: confirm general conversation.
2. M01: confirm conversational memory.
3. Q01: confirm market-data agent routing.
4. E01: confirm multi-step quote plus news routing.
5. N05: confirm no-news honesty.
6. P01: confirm portfolio grounding.
7. A01: confirm explainable recommendations.
8. X01-X03: confirm MCP discovery and validation.
9. S01-S04: confirm grounding and safety boundaries.
10. U02-U07: confirm streaming, follow-ups, scrolling, and transitions.
